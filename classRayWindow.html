Detailed Description

Raylib Window class - a single concrete class implementing IWindow3 fully (which already IS-A IWindow2 IS-A IWindow via the interface chain), matching raylib itself : one native window, no separate 2D/3D window objects.

raylib switches to 3D through a global mode (BeginMode3D), not through a second object : splitting into three C++ types would describe nothing real. The active camera is held between beginMode3() and endMode3().

◆ pollEvent()

bool RayWindow::pollEvent ( )
inlineoverride

raylib has NO event queue : only state queries, refreshed once per frame by PollInputEvents() inside EndDrawing().

There is nothing to drain here, and nothing to guard against a second caller : the state is already frozen for the frame and every read is idempotent.

It answers true always, because raylib has no way to tell whether anything happened. Harmless as long as only the fronts sit inside the condition - with no event they are false anyway. See IWindow.
