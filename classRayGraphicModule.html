Detailed Description

Single concrete class implementing IGraphic3Module, which already IS-A IGraphic2Module via the interface chain - one createWindow()/ createSprite()/... implementation, exported under two dlsym entry points (getGraphic2Module/getGraphic3Module) in sources/raylib.cpp, both returning this same instance.
