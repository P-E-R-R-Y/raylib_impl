Detailed Description

Raylib Sound class - a LoadSoundAlias() of a RaySoundBuffer, does not own the buffer. Deleting the sound never touches the buffer.

play() restarts the sound, where raylib would overlap playbacks by default. This is the only deliberate divergence from IMusic::play() : an ISound is a one-shot, not a transport.
